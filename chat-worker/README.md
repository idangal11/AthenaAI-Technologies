# צ'אטבוט AI לדף הנחיתה (Cloudflare Worker)

הדף ב-GitHub Pages הוא סטטי, ולכן אסור לשים בו את מפתח ה-API של Claude (כל גולש היה יכול להעתיק אותו ולהשתמש בו על חשבונך).
התיקייה הזו היא שרת קטן וחינמי ב-Cloudflare שיושב באמצע:

```
גולש בדף  →  Cloudflare Worker (מחזיק את המפתח + המידע על העסק)  →  Claude API
```

- `src/knowledge.js`: כל מה שהבוט יודע על העסק (חבילות, מחירים, שאלות נפוצות) ואיך הוא מדבר. כאן משנים תוכן.
- `src/index.js`: השרת עצמו. מקבל את השיחה מהדף, שולח ל-Claude, ומחזיר תשובה. כשגולש משאיר שם וטלפון בצ'אט, הוא נשמר בגיליון הלידים ונשלח אליך למייל (דרך אותו Google Apps Script של הטופס).
- `wrangler.toml`: הגדרות: איזה מודל, מאילו אתרים מותר לפנות, מגבלת הודעות לכל גולש.

## הגדרה חד-פעמית (כ-15 דקות, בלי טרמינל)

### 1. מפתח API של Claude
1. נכנסים ל-https://platform.claude.com ונרשמים.
2. **Billing**: מוסיפים קרדיט (5$ מספיקים להמון שיחות), ומגדירים **מגבלת הוצאה חודשית** (למשל 10$) כדי שלא יהיו הפתעות.
3. **API Keys** → **Create Key** → מעתיקים את המפתח (מתחיל ב-`sk-ant-`). שומרים אותו רק אצלך, לא בצ'אט ולא בקוד.

### 2. העלאת השרת ל-Cloudflare
1. נרשמים בחינם ל-https://dash.cloudflare.com.
2. **Workers & Pages** → **Create** → **Import a repository** → מחברים את GitHub ובוחרים את `AthenaAI-Technologies`.
3. בהגדרות הבנייה: **Root directory** = `chat-worker` (השאר כברירת מחדל) → **Deploy**.
4. אחרי שהעלייה מסתיימת: נכנסים ל-Worker ‏`athena-chat` → **Settings** → **Variables and Secrets** → **Add** → סוג **Secret**, שם `ANTHROPIC_API_KEY`, ובערך מדביקים את המפתח → **Deploy**.
5. מעתיקים את כתובת ה-Worker (נראית כמו `https://athena-chat.<השם-שלך>.workers.dev`).

### 3. חיבור לדף
שולחים לי את כתובת ה-Worker (הכתובת, לא המפתח), ואני מכניס אותה לשורה `var CHAT_ENDPOINT = "";` ב-`index.html`.
כל עוד השורה ריקה, הצ'אט בדף עונה בתשובות מוכנות מראש, כך שאין שום דבר שבור בינתיים.

מעכשיו כל שינוי בתיקייה הזו ב-GitHub (למשל עדכון מחירים ב-`knowledge.js`) מעלה את השרת מחדש אוטומטית.

## עלות
המודל: Claude Haiku 5.5 ‏(0.10$ למיליון טוקנים נכנסים, 0.50$ למיליון יוצאים). ההוראות והמידע על העסק נשמרים במטמון (prompt caching), אז הם כמעט לא עולים מההודעה השנייה והלאה.
הערכה גסה: בערך 0.0005$ להודעה, כלומר בסביבות 2,000 הודעות של גולשים לדולר אחד. מגבלת ההוצאה בקונסולה היא רשת הביטחון.
Cloudflare Workers חינמי עד 100,000 בקשות ביום.

הגנות מובנות: רק הדף שלך יכול לפנות לשרת, עד 15 הודעות לדקה לכל גולש, הודעה עד 1,000 תווים, ותשובות קצרות.
רוצים תשובות חכמות יותר? משנים ב-`wrangler.toml` את `MODEL` ל-`claude-sonnet-5-5` (בערך פי 20 יותר יקר).

## בדיקה מקומית (למפתחים)
```
cd chat-worker && npm install
echo "ANTHROPIC_API_KEY=sk-ant-..." > .dev.vars
npx wrangler dev
```
